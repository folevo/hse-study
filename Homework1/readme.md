# Магистратура «Искусственный интеллект»

Репозиторий содержит выполненные практические задания и проекты, разработанные в рамках **нулевого модуля** программы магистратуры.

## 📌 Описание
Цель данного модуля — выравнивание базовых знаний, освоение основ программирования на Python, работы с данными и инструментами анализа (включая Pandas Profiling / YData Profiling, Git и базовую математику для ИИ).

## 📂 Структура репозитория
* `/Homework1` — файлы с практическими заданиями.

## 🛠️ Используемые технологии
* Python 3
* Git / GitHub
* Jupyter Notebook / Google Colab
* YData Profiling (Pandas Profiling)
